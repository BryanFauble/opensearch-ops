How good is each recipe, really?

We keep a golden set of realistic searches where we already know which tool(s) the user wants. This runs every selected recipe over all of them and scores where the right answers landed. Higher MRR / Recall / Hit is better; lower speed (ms) is better. Scored against column A's field boosts (see the playground).
